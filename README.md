# Library Management System (C++)

## Description
A C++ console-based application to manage library records using Object-Oriented Programming and file handling.

## Features
- Add new books
- Issue books
- Return books
- Search books by title
- Search books by author
- Display all books
- Store records using files

## Technologies Used
- C++
- OOP Concepts
- File Handling

## How to Run
g++ main.cpp -o app
./app

## Sample Operations
1. Add Book
2. Issue Book
3. Return Book
4. Search Title
5. Search Author
6. List All Books
